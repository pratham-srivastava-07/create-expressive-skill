# Assets

Binary assets referenced by the top-level `README.md`. Add these files here:

- `logo.png` — square skill logo.
- `banner.png` — wide header image for the README.
- `demo.gif` — short screen capture of the skill scaffolding a project end to end.

These are for GitHub presentation only. They are **not** loaded by the skill at runtime and
have no effect on token usage — keep them out of `SKILL.md`.
